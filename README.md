# tax-expert

Workspace for preparing US and Canadian tax filings (Canadian citizens on TN visas, living in Florida).

Start here:
1. [docs/01-situation-and-risks.md](docs/01-situation-and-risks.md) – what applies to us and what could go wrong
2. [docs/02-open-questions.md](docs/02-open-questions.md) – answer these first
3. [docs/03-master-checklist.md](docs/03-master-checklist.md) – everything needed, by area
4. [docs/04-filing-tools.md](docs/04-filing-tools.md) – software/portals, and what can (not) be automated
5. [docs/05-deadlines.md](docs/05-deadlines.md) – calendar

New tax year: `scripts/new-year.sh 2026` then ask Claude to run the `year-setup` skill.
